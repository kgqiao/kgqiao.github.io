# Public Assets Directory

Place your custom images, PDFs (e.g. resume), and media files here.
Files placed in this directory are served directly at the root URL path.

For example:
- `public/avatar.jpg` -> accessible in your data files as `"/avatar.jpg"`
- `public/art/landscape.jpg` -> accessible as `"/art/landscape.jpg"`
- `public/projects/thumbnail.png` -> accessible as `"/projects/thumbnail.png"`
